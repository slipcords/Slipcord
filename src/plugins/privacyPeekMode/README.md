# PrivacyPeekMode

Blurs the Discord surface after a period of inactivity or when the window loses focus, hiding message content from anyone glancing at your screen - only unread indicators stay visible.

## Features

- Configurable idle delay before the surface blurs
- Separate toggle to also blur on window blur / tab hide
- Adjustable CSS blur radius
- Optional persistent unread-count badge while content is hidden
- Clears automatically on mouse movement, focus, or tab visibility

## Settings

- **Idle delay** - seconds of inactivity before blurring
- **Blur radius** - strength of the blur effect
- **Blur on window blur** - also blur when the window/tab loses focus
- **Show unread badge** - keep a visible unread badge while content is hidden

> Note: This applies a pure-CSS blur to the app surface. It does not encrypt content.
