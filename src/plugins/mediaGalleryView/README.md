# MediaGalleryView

Browse all image, GIF and video attachments cached in the current channel as a masonry gallery.

## Features

- Chat-bar button (only shows when the channel has media)
- Grid of thumbnails that lazy-load
- Toggle image, GIF and video inclusion independently
- Newest-first sorting
- Caps at a configurable maximum to keep the modal responsive

## Settings

- **Max items** - cap on rendered media
- **Include images / GIFs / videos** - which attachment types to show
- **Sort by newest** - chronological order toggle
